# 📊 Data Analysis – ERP / PDV Food

## 📌 Contexto
Este projeto simula análises de dados realizadas em um ambiente de ERP/PDV
para o segmento food, com foco em suporte técnico, operação e produto.

Os dados e cenários são inspirados em situações reais do dia a dia
(sem uso de dados sensíveis ou reais).

---

## 🎯 Problema de Negócio
Alto volume de chamados operacionais impactando:
- SLA de atendimento
- Experiência do cliente
- Estabilidade do produto

---

## 📂 Dados Utilizados
Base simulada de tickets contendo:
- Data e hora do chamado
- Tipo de problema
- Sistema afetado
- Tempo de resolução
- Prioridade

Formato: CSV

---

## 🔎 Análises Realizadas
- Volume de chamados por tipo
- Horários de pico
- Sistemas mais impactados
- Tempo médio de resolução (SLA)

---

## 💡 Insights para Produto
- Identificação de funcionalidades críticas
- Oportunidades de melhoria no produto
- Sugestões de automação e prevenção

---

## 📊 Métricas Acompanhadas
- SLA médio
- % de incidentes críticos
- Tempo médio de resolução
- Reincidência de problemas

---

## 🔄 Próximos Passos
- Análise com SQL
- Visualizações (BI)
- Uso de Python para automação
- Aplicação de IA para classificação de chamados
